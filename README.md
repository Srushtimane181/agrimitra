

\# AgriMitra 🌱



AgriMitra is a full-stack agricultural assistance web application designed to help farmers access useful agricultural information and services through a simple and user-friendly interface.



\## Project Structure





agrimitra/

├── frontend/    # React + Vite frontend

├── backend/     # Node.js + Express backend

└── README.md





\## Features



\* User registration and login

\* JWT-based authentication

\* User profile

\* Crop management

\* Crop details and updates

\* Agricultural schemes information

\* Disease information

\* Farming tips

\* Feedback functionality

\* Frontend and backend API integration

\* MongoDB database integration

\* Automated testing

\* Error handling and validation



\## Technology Stack

\## Running the Project



\### Frontend





cd frontend

npm install

npm run dev





\### Backend



Create a `.env` file inside the `backend` folder with the required environment variables.



Then run:





cd backend

npm install

npm run dev





\## Testing



\### Frontend





cd frontend

npm test





\### Backend

cd backend

npm test
